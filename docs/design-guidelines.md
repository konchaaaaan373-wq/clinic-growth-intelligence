# デザインガイドライン

UI・レポート（画面/PDF）の見た目に関するルール。コピーライティングの原則は
`product-philosophy.md` §8 を参照してください。

## 1. アイコン（絵文字の使用禁止）

**ルール: UIにOS依存のデフォルト絵文字（🏆 📚 🚀 など）を一切使用しない。**

- 絵文字はOS・ブラウザ・PDF出力で見た目が大きく変わり、レポートの品質が
  環境に左右されるため。
- アイコンはすべて **@phosphor-icons/react** を使用し、ウェイトは **duotone** に
  統一する（親しみやすさと文書らしさの両立）。
- 集患スタイルのアイコンは `ClinicStyleIconKey`（`src/lib/types.ts`）で管理し、
  `src/components/StyleIcon.tsx` で解決する。新しいスタイルを追加するときは
  キーとアイコンの対応をここに追加する。
- 旧レポート（localStorage保存分）に残る `emoji` フィールドは表示に使わず、
  `StyleIcon` の互換マッピングでアイコンに変換する。
- 「✓」「△」「？」「→」などの文字記号（テキストグリフ）は絵文字ではないため
  使用してよい。ただし色は tailwind のテーマカラーで統一する。

## 2. フォント

風船テーマに合わせた3系統のペアリング（すべてGoogle Fonts、`display=swap`）。
未読込時はOSの日本語ビジネス文書向けスタックへフォールバックする
（`tailwind.config.ts` の `fontFamily`）。

- **見出し（`font-display`）**: 欧文・数字 = **Quicksand** / 和文 =
  **Zen Maru Gothic**。どちらもジオメトリックな丸ゴシックで、風船の
  フォルムと揃える。総合スコアの大きな数字・ボタン・番号チップにも使う。
  Quicksand は **700 が上限** のため `font-black`（900）は使わない
  （欧文が混ざると1行内で太さが割れる）。
- **本文（`font-sans`）**: **Zen Kaku Gothic New**。見出しの Zen Maru Gothic と
  同じ骨格の角ゴシックで、統一感と本文の可読性を両立する。
- **桁揃えが必要な数値**: **Inter**。和文Webフォントは `tnum`（等幅数字）
  非対応のため、`tabular-nums` を指定した箇所には `.tabular-nums`
  （`globals.css`）経由で Inter を優先適用する。
  **「桁を揃えたい場所 = `tabular-nums` を指定する場所」** の対応を崩さない。
- 本文はカーニング（`kern`）有効・字間 0.01em。見出しは加えて
  プロポーショナル詰め（`palt`）＋字間 0.02em（丸ゴシックは詰めすぎると
  窮屈になるため）。h1/h2 は `text-wrap: balance`。

## 3. 文体（機械生成調の禁止）

- 全角引用符「“ ”」は使わず「」を使う。
- 文中の区切りにemダッシュ「—」「——」を使わない（句読点・「：」・「｜」で代替）。
- JSX内で日本語の文を改行で分割しない（レンダリング時に文中へ半角スペースが
  入るため）。長い文はテンプレートリテラルで1つのテキストノードにまとめる。
- 決まり文句的な比喩（「霧の中」「化けます」等）より、観測事実に基づく
  具体的な表現を使う。

## 4. 配色・データ表現（風船テーマ）

キービジュアル（Canvaで作成した手描き風の風船の束、
`public/images/balloons-hero.png`）から採色したパレットを使う。

- 基調は **コーラル（brand）**・背景は **クリーム（cream）**。
  境界線・分割線は warm gray（`slate` を上書き）で温かみを保つ。
- アクセントは風船カラー **sunny / mint / sky / lavender / peach** を
  `src/lib/palette.ts` の `balloonColor()` / `sectionColor()` で循環させる。
  これは **領域・番号の識別のための彩り** であり、良し悪しの意味は持たせない。
- **信号機色（緑=良い/赤=悪い）は使わない。** 注意喚起はアンバー。
  低スコアを「失敗」として演出しない（グレードバッジは brand 単色）。
- スコアバーはカテゴリ満点を全幅とし、**獲得分（領域カラー）／評価済み未達分
  （薄地）／未評価分（斜線ハッチング）** の3状態で示す。未評価を満点と
  同じ見た目にしない（unknown ≠ weak の可視化）。
- **白文字を載せる塗り（番号チップ等）はコントラスト比 4.5:1 以上** の
  深い色（各色の800番台、「風船の影」のトーン）を使う。鮮やかな600番台は
  文字を載せないバー・下線などに限る。
- 装飾（浮かぶ風船 `BalloonMark`・波線マーカー `marker-underline`・
  紙吹雪 `confetti-bg`）は `aria-hidden` の飾りに徹し、本文の意味を
  装飾に依存させない。

## 5. 印刷（PDF）

- 1ページ目は「総合スコア＋総評＋今すぐ直すべき3点」の結論ページとして独立させる。
- 集患スタイル診断は専用ページに送る（`print-page-break`）。
- 画面専用UI（ボタン・ファネル等）は `no-print`。ただし配布資料として必要な
  次のステップ・連絡先は印刷専用ブロックで必ず残す。
- 白文字＋色背景の要素（番号チップ等）とスコアバーの塗りは
  `print-color-adjust: exact` の対象に含め、「背景グラフィック」設定に
  依存させない（背景が印刷されないと白文字が見えなくなる）。
  紙吹雪などの画面向け装飾は印刷では出さない。

## 6. ブランドの一貫性（風船ビュー）

- **下層ページの見出し帯は `PageHero`**（`src/components/PageHero.tsx`）を使う。
  クリーム地＋薄い紙吹雪＋浮かぶ風船で、どのページでも同じ「顔」にする。
  トップページのみ大きな `Hero`（キービジュアル入り）を使う。
- 装飾の風船は `BalloonMark` / `BalloonTrio` を使い、SVGを都度手書きしない
  （フォルムのばらつきを防ぐ）。
- ファビコンは `public/favicon.svg`（コーラルの風船）、OGP画像は
  `public/images/ogp.png`（キービジュアルの1200x630クロップ）。
  キービジュアルを差し替えたらOGPも再生成する（`index.html` の og:image は
  絶対URLのため、ドメイン変更時に更新が必要）。

## 7. キービジュアル（Canva）

- 風船のキービジュアルは Canva で作成・管理する
  （デザイン名: Joyful Balloons Against Cream Sky Illustration）。
  差し替え時は Canva で編集 → PNG エクスポート →
  `public/images/balloons-hero.png` を更新する。
- イラストは手描き・水彩調のタッチを保つ（フラットな「AIっぽい」
  生成画像調にしない）。背景はクリーム（cream トーン）で、
  サイトの背景色と馴染ませる。
